# Codex Quiz

Codexの使い方を、実務で迷う操作の選び方を通じて学べる無料の4択クイズです。OpenAI公式ドキュメントを根拠に作成した非公式教材で、ログインや外部APIは必要ありません。

**[ブラウザで始める](https://ip-san.github.io/codex-quiz/)**

## 学び方

初回は短いチュートリアルで学び方を確認できます。その後、9分野を18問で見渡せる「全体像モード」から始めてください。回答後は、正解の理由だけでなく、選んだ選択肢が違う理由も確かめられます。必要な問題では図解やターミナル操作例も見られます。

気になる分野はカテゴリ別・難易度別に練習できます。「読んでから解く」では、分野を選び、判断の理由を5つ読んでから同じ5問で確認します。実務の手順を追うシナリオ、ランダム10問、100問の実力テストもあります。認証や接続の失敗を切り分ける問題も収録しています。

## 主な機能

- 9カテゴリ・264問。各問題からOpenAI公式資料を参照可能。件数の水増しより、実際の判断に役立つ設問を優先
- 15の実践シナリオ、問題を探してから詳細を開ける解説リーダー、検索・ブックマーク
- 苦手問題と復習時期に合わせた練習、進捗の確認
- 学習の途中再開と、JSONファイルによるデータの書き出し・読み込み
- スマートフォン対応、ホーム画面への追加、取得済み内容のオフライン利用

学習データは使用中のブラウザに保存され、端末間では自動同期されません。端末を変える前やブラウザのデータを消す前に、進捗画面からバックアップしてください。

## 開発者向け

ローカルで動かすにはNode.js 22.19以上が必要です。

```bash
npm ci
npm run dev
```

変更後の検査は `npm run check` を使います。画面の作業中は短いブラウザ検査も使えます。公式資料の変更から再確認すべき問題を探す方法は、[品質運用](docs/QUALITY_OPERATIONS.md)にまとめています。環境構築・テスト・公開手順は[開発ガイド](docs/DEVELOPMENT.md)、問題の出典と品質基準は[ドキュメント一覧](docs/README.md)を参照してください。変更履歴は[開発履歴](docs/DEVELOPMENT_HISTORY.md)へ分けています。

Codexは更新されるため、問題の内容は公式資料との継続的な再確認が必要です。認証やCloud環境の設定は利用条件によって異なるため、実作業では各問題の公式資料も確認してください。このアプリはOpenAIの公式製品ではありません。
