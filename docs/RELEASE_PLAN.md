## 運用

各回git status/logとこの計画を確認。ユーザー変更は保護する。実装に応じてテストとREADME・CONTENT_COVERAGEを更新。完成単位で検査、commit、push、GitHub Actions、公開反映まで確認する。失敗中の項目は完了にしない。重大な判断や新しい権限が必要な場合のみ相談する。

必須項目がすべて完了したら自動実行を停止し、完成内容と残存制約を報告する。追加の改善候補を完了条件へ無断で追加しない。
