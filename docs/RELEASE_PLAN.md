# 公開品質までの開発計画

## 完成条件

初心者が案内から学習を始め、結果から復習し、保存した進捗を使って継続できること。既存データを壊さず、スマホで主要操作ができること。必須項目の実装と検証、mainへの反映、公開確認を終えた時点で完成とする。

問題数は目標にしない。Desktop版、AI推薦、課金、通知、修了証、テーマ追加は今回の対象外。

## 運用

各回git status/logとこの計画を確認。ユーザー変更は保護する。実装に応じてテストとREADME・CONTENT_COVERAGEを更新。完成単位で検査、commit、push、GitHub Actions、公開反映まで確認する。失敗中の項目は完了にしない。重大な判断や新しい権限が必要な場合のみ相談する。

必須項目がすべて完了したら自動実行を停止し、完成内容と残存制約を報告する。追加の改善候補を完了条件へ無断で追加しない。

## 初回監査

- 初心者案内、結果のおすすめ、解説の復習フィルター、問題へのリンクは実装済み。
- 現在263問、図解57問、terminal例31件。
- ブラウザ検査21件、ユニットテスト23件が直近の基準。
- カテゴリの既存バーは直近正解数であり、回答済みの章進捗とは区別する。
- 未追跡debug.logは既存ファイルとして保護し、公開対象に含めない。
- 2026-09-20：R1〜R6を完了。公開品質までの開発を終了し、自動実行を停止する。今後の仕様追従や新機能は別の保守・開発範囲とする。

## 残存制約

- 公式資料の最終照合は実践シナリオ9問。他の問題は各verifiedAt時点の確認であり、今後の仕様変更への追従は保守作業とする。
- オフラインは取得済みデータが対象。未訪問端末での初回オフライン起動は対象外。
- 進捗はブラウザ保存で、端末間同期はJSON移行。サーバー同期・アカウントは対象外。
- Chromiumによる自動検証が中心。iOS実機や全ブラウザの互換性保証は行わない。
